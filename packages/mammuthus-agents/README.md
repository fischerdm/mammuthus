# mammuthus-agents

Agentic components for non-life (P&C) insurance pricing, built on mammuthus tools.

Part of [mammuthus](https://pypi.org/project/mammuthus/), agentic AI for
non-life (P&C) insurance pricing. This package is at an early stage.

## Installation

```bash
pip install mammuthus-agents
```

```python
import mammuthus.agents
```
